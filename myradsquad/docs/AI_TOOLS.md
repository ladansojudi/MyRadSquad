# AI tools used

1. **Claude Code** — built the working iOS app with me in code (Expo / React Native) from my
   direction and screen-by-screen feedback on the simulator; also desk research (age-gate
   rules, A/B test planning) and first drafts of the experiment note and test plan.
2. **Claude Artifacts** — the research dashboard: research questions, sources, problems,
   "how might we" and the six solutions the app is built on.
3. **ChatGPT image generator** — reference images to explore an illustration style
   (characters, avatars); the final avatars are drawn in code from that direction.
